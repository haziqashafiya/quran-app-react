📖 Quran App

Aplikasi Al-Qur'an sederhana berbasis React dengan UI modern (Pink Theme).

🚀 Fitur

- Baca Al-Qur'an
- Jadwal Sholat
- Kalender Hijriah
- Dark Mode
- Tasbih Digital

🛠️ Tech

React + Vite + Tailwind + lucide-react
